ClStats Server – what this server stores

This is a self-hosted ClStats server. Whoever runs it is responsible for it; it is not operated by the developer of the ClStats app.

Stored data

  • The claude.ai session cookie sent by the ClStats app, encrypted at rest with the server's secret key.
  • Usage samples read from claude.ai every few minutes: percentages and reset times of the plan limits.
  • Optional: token totals per day, project and model sent by the token script (counts only, no content).
  • Optional: push tokens of devices, only if push notifications are configured on this server.

Connections

The server talks only to claude.ai (and, if configured, to Apple's push service). It loads no third-party content, sets no cookies and has no tracking or analytics.

Deletion

"Sign Out" in the app removes the cookie. Deleting the server's data volume removes everything else. Ending the session on claude.ai makes a stored cookie useless.

Deutsch

Dies ist ein selbst betriebener ClStats-Server. Verantwortlich ist, wer ihn betreibt – nicht der Entwickler der App ClStats.

Gespeichert werden: das Sitzungs-Cookie von claude.ai (verschlüsselt), Messwerte der Nutzungslimits (Prozent und Reset-Zeiten), optional Token-Summen pro Tag, Projekt und Modell (nur Zähler, keine Inhalte) und optional Push-Tokens von Geräten. Der Server spricht nur mit claude.ai (und ggf. Apples Push-Dienst), setzt keine Cookies und hat kein Tracking. „Abmelden“ in der App löscht das Cookie, das Löschen des Daten-Volumes alles Übrige.
